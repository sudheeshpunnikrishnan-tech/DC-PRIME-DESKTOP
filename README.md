# DC Prime Desktop Application
Official lightweight desktop companion app for **Davis & Company, Aluva**.

### Features:
- Ultra-low RAM & fast startup performance.
- Material 3 Dark theme.
- Complete Rice & Provisions Price List directory with instant search.
- Taxable & Non-taxable ledger indicator compatible with TallyPrime.
- Customer directory with B2B, B2C and delivery remark details.

### How to Download:
1. Go to the **Actions** tab in this repository.
2. Select the latest completed run (**Build DC Prime Desktop**).
3. Under the **Artifacts** section at the bottom, click **DC_Prime_Windows_App** to download the ZIP package.
4. Extract the ZIP and double click `dc_prime_desktop.exe` to run.
